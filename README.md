# HR Analytics Dashboard

## 📊 Project Overview

This project is an interactive **HR Analytics Dashboard developed using Tableau**.

The dashboard analyzes employee data to understand workforce distribution, salary, performance, experience, work mode, hiring trends, and employee attrition.

## 🛠️ Tools & Technologies

* Tableau
* Excel / CSV
* Data Analysis
* Data Visualization

## 📌 Key Performance Indicators

* Average Salary: ₹8,96,887
* Average Performance Rating: 3.0
* Average Experience: 5 Years
* Attrition Rate: 30%
* Total Employees: 1,048,575

## 📈 Dashboard Features

* Total Employee Count
* Average Salary
* Average Experience
* Average Performance Rating
* Attrition Rate
* Employees by Department
* Employees By Work Mode
* Salary Distribution
* Employees Hired Over Time
* Interactive dashboard filters
* KPI cards for quick HR analysis

## 💡 Key Insights

* The dashboard provides an overview of employee distribution across departments.
* Average salary can be compared across different departments.
* Employee performance ratings can be analyzed through the performance distribution.
* Work mode distribution provides insights into different working arrangements.
* Hiring trends show how employee numbers have changed over time.
* Salary distribution helps identify the salary ranges where employees are concentrated.
* The dashboard provides an overall view of employee attrition.

## 🎯 Project Objective

The objective of this project is to transform HR employee data into an interactive Tableau dashboard that provides clear and meaningful workforce insights through data visualization.
